# Code language

- **English by default** in ALL code: identifiers, names, comments and messages. MANDATORY in "outward-facing" code (distributable, FWP, back/front that a third party/customer sees).
- **Neutral Spanish** (tú/resuelve/sube): an exception ONLY for our own internal tools (the owner's personal scripts). NEVER Argentine voseo (vos/resolvé/subí) nor Chilean slang, in any case.
