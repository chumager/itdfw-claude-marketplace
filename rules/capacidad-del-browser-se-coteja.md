# What a browser supports is checked on caniuse or MDN, never from memory

Before claiming that a browser does or does not support an API, a CSS feature or a format (or before asking for a fallback because of it), consult caniuse.com or MDN (its compatibility table), and the claim goes with the source.

- Not from memory nor from a blog, a forum or an answer on another site: support changes with every version.
- If it could not be checked, say "unverified" and do not turn it into a requirement.
