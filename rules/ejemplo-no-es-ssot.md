# An example is NOT SSoT

In someone else's document, "e.g.", "for example", "like", "such as" and "(…)" mark an illustration, not a definition: they do not close the list, do not fix the mechanism, do not frame the scope.

- When quoting, the "e.g." is kept: cutting it is an unfaithful quote.
- When reasoning, the author is not credited with having chosen what he only illustrated.
- If the example is the only thing about a point, the point is undefined: ask.
- 🔴 **A number said in passing is not a goal.** Before turning it into an assertion or a TDD row: "is this a goal or a reference?". A comment turned into a test becomes dogma.
- 🔴 It weighs more in business logic: a model built on an example is a model built on an anecdote.
