# Load the skill BEFORE implementing

Before implementing or touching code in an area (front, mongoose-types, plugins, fwplugin, core-init, models, api-system, etc.), FIRST check whether a skill exists for that area and invoke it with the Skill tool. Do not wait for the user to ask "did you load the skill?".

Having the SKILL.md in context from a post-compact is NOT enough: invoke it fresh with the Skill tool before acting.
