# An artifact the owner is commenting on is NOT REPUBLISHED until his closing comment

While the owner comments on a published artifact, the owning session does not change the document under him: it does not republish it or edit it. When he finishes, he leaves a closing comment ("artefacto leído", i.e. "artifact read"); only then are all the changes applied together and the page republished.

| While he comments | What is done |
|---|---|
| answer a comment in its thread (also the automatic reply) | yes, right away and short: the quick conversation is useful to him |
| change the page (republish, edit) | no: it moves the document while he reads and he does not know what changed |
| work on what was commented (TDD, code) | it is noted; applied after the closing, all together |
| resolve a thread | no: he closes his own threads |

- An automatic reply does not read the whole thread and may ask again what was already decided: the owning session corrects it if it gets it wrong.
