# The closing of an assignment returns through the same chain it came through

An assignment that passed through several sessions (owner → itdfw → a project session → an implementer session) is closed UPWARD, link by link: each one notifies whoever handed it to them, until it gets back to whoever asked for it.

- Whoever reviews or closes (the CTO too) notifies the one who sent it to them **and** the owner of the assignment; notifying only the one who reported is not enough.
- The notice is one line: what was closed and where the detail is. No opinions or analysis that nobody asked for.
- In a room, speak only if you bring something the rest do not have; anything else is noise that drains context.
